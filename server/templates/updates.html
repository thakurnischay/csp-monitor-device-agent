Agent Updates

Release a new agent version and roll it out to chosen CSPs. Updates are signed with your offline key, downloaded by each agent over HTTPS, verified, installed with automatic rollback, and only counted as Successful after the new version reports healthy.

{% if not keys_installed %}
No release-signing public key is installed on this server, so releases cannot be uploaded. Put your public key in release_public_keys.json (see UPDATES.md).
{% endif %}

1. Upload a signed release

Create it on your own machine with release_tool.py build; upload the three files it produces. The server re-verifies the signature and every file before accepting it.
