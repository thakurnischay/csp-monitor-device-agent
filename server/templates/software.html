Micro-ATM software

The agent on each CSP reports which Ingenico software is installed, its version, whether it is open and whether it crashed. You set the version that is required here. When a new version is released, change the number once and every CSP is checked against it on its next report - no agent update is needed. A CSP whose micro-ATM is not an Ingenico terminal is never judged.
