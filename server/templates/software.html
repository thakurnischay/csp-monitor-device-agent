Device software

The agent on each CSP reports which vendor software is installed for its micro-ATM, GPS dongle and fingerprint scanner, with its version (and, for LLT, whether it is open and whether it crashed). You set the version that is required here. When a new version is released, change the number once and every CSP is checked against it on its next report - no agent update is needed. A CSP whose device is of another make is never judged against software that does not belong to it.
